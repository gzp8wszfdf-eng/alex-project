# Airport Director — Unity rebuild

This branch starts the native 3D rebuild of the Airport Director prototype.

## Target
- Unity 6.0 LTS (6000.0)
- Mobile-first 3D management simulator
- Landscape orientation
- URP can be added after the first playable scene is stable

## Open the project
Open this repository as a Unity project in Unity Hub. The Unity editor is required to import assets, create builds and test on a device.

## First milestone
A playable greybox airport scene: runway, taxiway, terminal, apron, a controllable camera and a procedural aircraft.

## Planned milestones
1. Core airport scene and camera.
2. Aircraft taxi, takeoff and landing state machine.
3. Passenger and ground-service simulation.
4. Airport management, missions, economy and progression.
5. Production art, audio, optimization and mobile UI.

The existing browser prototype remains on `main`; this branch is the separate Unity rebuild.
