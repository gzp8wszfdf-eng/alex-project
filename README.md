# Idle Airport Empire ✈️

Бесплатный мобильный 2D idle-tycoon прототип аэропорта.

## Запуск
Открой `index.html` в браузере или включи GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. После публикации игра будет доступна по адресу `https://gzp8wszfdf-eng.github.io/alex-project/`.

## Уже работает
- Стартовый баланс и пассивный доход
- Ручные рейсы и награды
- Улучшения терминала, полосы, персонала и сервиса
- Уровни аэропорта и сохранение прогресса на устройстве

Рекламная кнопка/интеграция пока не подключена: для настоящих рекламных показов потребуется рекламная сеть и её одобрение.
